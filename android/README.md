# Android App

This module is a clean WebView wrapper around the live Ajix Pharmacy web app:

`https://ajixpharmacy.online/`

That keeps Android and web on the same current build by design.

## Build

Open the `android/` folder in Android Studio, or run Gradle from this folder:

`gradle assembleDebug`

If you are building from the command line, make sure `ANDROID_SDK_ROOT` or `local.properties` points at your installed Android SDK.
